# P0/P1 离线实现验收

2026-10-18。**P0/P1的独立离线模块已实现，对应9项验收标准通过主机范围验收。** 未接入真实pandad、USB/SPI或固件；P2–P7尚未实施，不能据此部署或驾驶。

验收直接重放版本化的两份补丁到新目录，没有使用开发工作树作为测试源。配套官方基线保持 openpilot `35e78a9d`、panda `a5919516`、opendbc `b3bd79a6`；完整补丁提交、文件SHA、工具链和证据见 [result.json](result.json) 与 [补丁清单](../../patches/openpilot/p0p1/manifest.json)。

交叉审查后补充了四项回归：未知板型不能通过自报相同名称注册；宽地址/总线输入不能先截断再验证；上游重初始化可能产生的BRS=1/FD=0状态保留并标记不一致；浮点等值不能伪装成合法协议版本。全部包含在上述最终结果中。

复验命令：`python3 tools/validate_panda_compat.py`。完整实际输出留在忽略的results目录，版本化结果保留原始报告SHA。先前设计目录中的NOT_RUN是历史冻结状态，不覆盖本报告；P2–P7不因此变为完成。CI没有在本轮执行。

本轮没有连接C3XL、发送真实CAN、修改系统、切槽、启动设备服务、reset或刷Panda，也没有构建MCU固件。真实身份、MCU/PCB、bootstub、恢复能力与驾驶员相机差异继续保留；本轮完成不改变这些实机条件。
