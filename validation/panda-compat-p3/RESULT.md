## 关键行为

槽位由 profile 身份绑定确定，不按枚举次序、板型或剩余板数排序。掉板后
槽位保留，幸存板不会接管另一板的总线。完整连接匹配仅意味着结构可用，
真实 device/TX/firmware 权限仍恒为 false。

新 handle 使用逐身份单调递增 token；同一活动 token 的重复枚举不改变代次，
退役 token 和迟到回调不能复活连接。正常掉板/重连示例：故障槽 epoch
`1→2→3`，健康槽保持 `1`，组 generation `1→2→3`。新板身份必须建立
新的显式绑定，不能继承旧 slot 的队列。计数溢出永久关闭注册表，不回绕。

任何连接或组代次变化均让双板旧 TX、RX 和半帧失效，即使路由器在掉线与
重连之间没有被调用。TX 批次还必须携带入口捕获的组代次，防止尚未入队的
旧批次重连后进入新会话。出队对象在模拟发送/发布前再次核对代次和年龄。

总线映射为 `host=4×slot+local`：slot0 对应0/1/2，slot1 对应4/5/6，
MCU wire 始终使用 local0/1/2。3/7、TX returned/rejected 标记和越界输入
拒绝；FD 受绑定能力约束。每板保持 FIFO，不声称双板硬件时间同步。

RX 保留首个分片的原始接收时间，完成、出队和再次检查均不刷新年龄。
过期半帧、坏校验/协议流或 RX 溢出关闭全组，不能清掉半帧后继续猜测同步。
TX 无效批次或溢出原子拒绝，不留下另一板的部分命令。故障不重放、不绕板。

## 冻结时限与尚未接入的部分

| 项目 | 候选上限/条件 |
| --- | --- |
| sendcan源年龄 | <100ms；明确收紧锁定上游的<1s，不称作原版行为 |
| TX队列停留 | <20ms；到达阈值即过期 |
| RX及残片年龄 | <100ms；保留原接收时间 |
| 容量 | TX64帧/槽、RX256帧/槽、单批最多64帧 |
| 时钟异常 | 未来时间拒绝；router时钟回退/回绕使该router永久失效，需新实例 |

以上是模拟时钟下验证的候选资源策略，不是 C3XL 的实测实时性能。P2 的
内部待发 IO 队列仍为0；P3 队列是其上层的路由暂存，不改变 P2 不重放语义。

超过两项的 inventory 在检查候选前直接拒绝，退休当前活动连接，不登记
未检查的新 token；两项重复身份则消耗其已知候选 token。两种情况都清理
旧活动组，不能靠删除额外项恢复旧活动 token 或旧队列。该边界已记录和测试。

注册表和路由器按单一串行事件循环调用，内部不持设备 handle、不执行 IO。
集成测试显式将模拟 intent 交给 fake P2 后端，并把失败回报给注册表。
实际发现/回调/消息入口仍需 P4 接线；不能把旧消息重新贴上当前代次。

P3 完整组可用性不包括 health新鲜度、safety配置读回或重新接合条件。
P4 仍需实现逐板屏障、offroad/配置与接合规则、消息消费者、heartbeat和
外围角色。没有完整活动 pandad 构建、MCU固件或车辆验收，不代表可以部署。
